# ムビコマ｜引継ぎ後の実コード修正・検証記録（2026-11-12）

## 目的
ユーザーが承認したデザイン・カード・動画・無料枠・保存作品を変えず、漫画の品質と保存失敗時の安全性を改善する。

## 修正1：ユーザーメモを未観測の出来事として扱わない
- 対象：`ios/COMICPOP/MangaStory.swift`、`ios/COMICPOP/VideoAndAI.swift`
- 従来、オフライン仮脚本の `plotDescriptionJP` と、AI脚本で `plotDescriptionJP` が欠けた場合に、カードの自由記述メモを「このコマで実際に起きる動作」に代入していた。
- 例：カードのメモ「怖く演出して」は、実際の行動を説明していない。それでも別の API プロンプトの「ACTUAL PLOT EVENT」に混入する可能性があった。
- 修正：動作の記述がない場合は `plotDescriptionJP` を空欄として残す。元メモは `userSceneNoteJP` と作画プロンプト内の高優先度 `USER'S ORIGINAL CARD NOTE` に保持。モデルが提案した具体的動作や手動編集した動作はそのまま利用する。
- これにより演出メモを消さず、観測していない出来事を事実として誤表示する危険を減らす。AIが提案した動作が映像と事実整合するかは別途人手レビューが必要。

## 修正2：コマ再生成の端末書き込み失敗時に変更を取り消す
- 対象：`ios/COMICPOP/StudioStore.swift` `regeneratePanel`
- 従来、再生成直後の絵・フィルター基準・試行回数をメモリ上で変更してからチェックポイント保存を行い、保存失敗時には旧状態を復元していなかった。アプリ画面・保存ファイル・次回の再試行シードが食い違う可能性。
- 修正：生成済みコマ画像、`finishingBase`、`panelRetryCount`、`dirtyArtworkIDs` を一時退避し、`saveDraftCheckpoint()` が失敗したらすべて復元。復元後はユーザーに旧画像を保持した旨を表示する。
- 追加 API 呼出しや自動課金は発生しない。再生成そのものは従来どおりユーザーの明示操作が必要。
