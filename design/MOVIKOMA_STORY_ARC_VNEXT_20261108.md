# ムビコマ・漫画生成エンジン｜ストーリー構成強化 vNext
更新：2026-11-08

## 最優先要件
動画内で選んだ場面に演出カードを刺すことで、**ストーリーとして読める漫画**を作る。切り出しフレームを1枚ずつ漫画フィルタするだけでは不十分。同時刻のカード（例：ドラマティック＋恐怖）は、物語上同じ出来事を1つのコマで描き、双方の感情・演出を合成する。

## 実装
### 1. 動画シーン単位の物語設計
- `CardSceneGrouping` と `ScenePlan.renderPins` が同時刻・近接時刻カードを一つのシーンに統合。挿入したカードは全件保持。
- 新規 `MangaNarrativeDirector.swift` はシーン数とカードの意味から、導入／伏線／展開／危機／リアクション／発見／クライマックス／回収／余韻／単一場面を判別する。
- 85種類の登録カードのうち、特に重要な料理系カード「挑戦・調理工程・失敗・完成料理・成功」と、感情カード「ドラマティック・恐怖・リアクション」を物語上の役割として解釈。
- 「忠実再現(exact)」「追加禁止(noextra)」「引用セリフ(quote)」「必ず使う(must)」などは、単なる装飾でなく**ユーザーが指定した脚色の制約**としてAIに渡す。
- 場面数が少ない動画に無理やり起承転結4コマを捏造しない。結末の証拠がなければ開いた終わり方を選ぶ。

### 2. 物語への因果関係付与
- `MangaStoryPlanner.evidenceJSON` は各シーンに `storyFunction`・`storyDuty`・`connectionToPrevious`・`suggestedShot`・`cardIDs`・`evidenceRestrictions` を追加。
- Cloudflare上の脚本AIには `causalLinkJP`（前コマとの因果・反応・結果を日本語で説明）を要求する。
- `MangaStoryBeat` には `narrativeDutyJP` と `causalLinkJP` を保存。既存のコマIDと挿入カードとの対応は保持。
- モデルが因果関係を返さない場合、適当な文章でごまかさず**脚本プレビューで警告**する。

### 3. 画像生成の重点を脚本に移す
- `VideoAndAI.swift` のプロンプト構造を再設計。**出来事・何を描くか・物語上の役割・前のコマとの因果・同時刻カードの融合**を先に並べ、長い説明で2400文字の上限に切り詰められないようにした。
- レックスUI、動画フレーム、画風/白黒、前に描いた漫画の人物同一性の参照方式は維持。
- 画像への文字の描画は禁止する指示を、切り詰めた後にも追加。日本語セリフ・ナレーションはiOS側で組版する。ただし画像AIが絶対に文字を描かないことまでは保証できない。

### 4. AI作画前の脚本品質ゲート
- `MangaStoryQualityAudit.swift` は以下を検出：出来事未記入／画面指示未記入／直前のコマと酷似した出来事／同一構図指示／前のコマとの因果欠落／具体性のない定型文。
- `PopStoryboardDraft.swift` で物語上の役割を表示し、「このコマで何が起きるか」「前コマとの因果関係」「ナレーション」「セリフ」「作画指示」を別々に修正できる。
- 注意点が残る場合、画像生成枠を使う前に確認を求める。AIの評価が誤る場合もあるため、ユーザーは意図的にそのまま進めることができる。
- 脚本を手直ししても画像APIを再実行せず、無料枠を浪費しない。

### 5. シーン数に合わせた出力容量
- `MangaStoryServices.swift` の文章AI出力上限をシーン数から計算（最小3000、最大6400トークン）。12シーンなど長い脚本でJSON後半が途中切れするリスクを低減する。上限値は実際の消費量ではない。
- Cloudflare Workers FreeのNeurons無料枠を保証するものではない。ユーザーの無料枠と対象モデルの可用性により呼出し結果が変わる。

## 次回の実機受け入れ基準
1. 料理動画で5つのシーンを指定すると脚本上に導入・実際の調理工程・トラブル/緊張・反応・完成（実際に映っている場合）が自然につながる。
2. ドラマティック＋恐怖を同時刻に刺したら**一つのコマ**となり、危機を感じる出来事と劇的な構図を両立する。
3. AIが前後を誤解した場合は、作画前に「このコマで起きる出来事」と「因果」を日本語で手直しでき、結果の絵に反映される。
4. 12シーンでもJSONの最後まで脚本があり、後ろのカードが消えない（実Cloudflare枠の制約を別途確認）。
5. 5つの別シーンなら5コマ2ページを生成し、漫画リーダーで最終ページまで閲覧できる。
6. 読めない文字・人物が別人になる・似た絵の連続が残った場合は不合格とし、モデル選定と参照画像戦略を継続改善する。
