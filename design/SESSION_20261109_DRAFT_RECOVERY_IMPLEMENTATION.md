# ムビコマ｜漫画生成の再起動復元と無料枠保護（2026-11-09）

## 結果
GitHub `zoukapu-design/comic-pop-ios` / `feat/movikoma-rex-reference-ui` に、AI脚本・ユーザー編集・生成済みコマを端末内に記録し、アプリ再起動後に回復する仕組みを追加した。

### 保存構造
- `ios/COMICPOP/MangaDraftCheckpoint.swift`：`MangaDraftCheckpoint` と `MangaDraftArtwork` を Codable として新設。
- `MangaStoryBeat` と `MangaStoryPlan` を Codable 化。日本語ナレーション、セリフ、構図指示、元カードメモ、因果関係も復元可能。
- `Application Support/COMICPOP/manga-draft.json`：現在の元動画名・全ピンカード・計画シーンID・画風・白黒カラー設定・生成方法・脚本・生成済み画像のファイル参照を原子保存。
- `draft-art-<UUID>.png`：各コマの生成画像を劣化なしPNGで保存。古い画像を直接上書きせず、新画像を保存してからJSONを原子的に切り替え、切替成功後に古いファイルを消す。
- 画像アップロードや追加API呼び出しはなし。Cloudflareのトークンもチェックポイントには保存しない。

### 実装した復元動作
- `StudioStore.init()` でチェックポイントを検査して脚本・生成済み画像を復元し、ページプレビューを再描画。
- 動画・カード（種類・時刻・追加／削除・元メモ・セリフ等）・計画シーンID・画風・色・脚本の生成方法が一致する場合のみ復元。
- 画像が欠損している場合は、復元できた**先頭から連続するコマのみ**保持し、壊れた途中以降を完成扱いしない。
- 既存の `GenerationIntegrity.canResume` と `MangaGenerationRoute` を使い、完了済みコマを再利用して不足分から処理再開。
- AI脚本作成、脚本編集、コマ生成完了ごと、セリフ修正、画像加工、単独コマ再生成、オリジナルへ戻す操作でチェックポイントを更新。
- Checkpointの保存失敗時は次のGPUリクエストを停止する。次の再開・コマ描き直しでも先に保存を試行。
- 明示的な結果破棄ではチェックポイントと一時PNGを削除。保存済み作品 `comic-*.png`、ピンカード元画像 `pin-*.jpg`、元動画は削除しない。

## 最新ビルド向けの実機受入ケース
1. Cloudflare AIで4つの時刻にカードを挿し、脚本を編集。いったんアプリを終了・再起動し、編集した脚本と元カードメモが一致すること。
2. 画像を途中（例：2/4コマ）まで生成した状態でアプリを終了・再起動。「続きを生成する」で**残り2コマのみ**処理されること。Cloudflare利用量はユーザーの管理画面と照合する。
3. 一つの場面へ2カードを挿し、1シーンに統合された脚本・画像が正しく復元されること。
4. 途中生成後、カードのメモや画風を変更し、**古い画像が新しい脚本と混ざらない**こと。
5. 生成結果を明示的に破棄しても、保存済み作品・元動画・カード・デッキが残ること。
6. 生成済みコマの日本語セリフと画質調整を行った後でアプリ再起動し、修正内容が維持されること。
7. 最新`ios-unsigned-check`が成功した後にのみ、署名つきTestFlightビルドを実施する。
