# ムビコマ UI v2｜実装指示書／画面遷移／受け入れ基準
更新日：2026-11-05。ユーザーが承認した青×黄色・ゴーグルのレックスの**3枚の参考画面**と、2026-11-05の全導線イメージをデザイン基準とする。

> **位置づけ**：この文書は「実装目標」と「操作上の真実」を定める仕様。生成したデザイン画像は開発中の実機スクリーンショットではない。未完成機能を画像どおり完成と扱わない。

## 0. プロダクトの中心体験
ユーザーが自身の**動画と音声**を選び、再生しながらシーンへカードを刺し、画風を選んで**1〜複数ページの漫画**を生成して保存する。漫画は動画の場面変化とカード指定を反映する。漫画内の人物や色の一貫性、音声のセリフ反映は品質目標であり、現状では保証しない。

## 1. 情報設計／画面遷移（実装ID）
メイン工程は常時 **①動画を選ぶ → ②編集（カード挿入） → ③漫画に変換** の3ステップとし、進行状況を下部バーで示す。ホーム・設定・作品一覧はこの工程を失わず開ける補助画面。
- `W00` 初回案内：レックス＋「動画を漫画にしよう」＋**はじめる**。次回以降はユーザー選択により省略できる。
- `W01` ホーム：最優先CTA「動画から漫画を作る」、次点「作品一覧」、メニュー「マイデッキ」「設定」。初見ユーザーに主要操作を分散させない。
- `W02` 動画選択：写真ライブラリ／ファイル、選択動画のタイトル・長さ・静止サムネイル、黄色CTA「この動画で編集を始める」。動画未選択時は無効。動画形式/権限/コピーエラーを同画面で説明する。
- `W03` カード挿入スタジオ：動画再生・時間指定・カード挿入・挿入済みピン一覧。主CTA「＋挿入」、次CTA「画風を選ぶ」。
- `W04` 画風選択：2列×3行のレックス付き6ジャンル、統一感設定、白黒/カラー、主CTA「この画風で漫画を作る」。
- `W05` 生成方法選択／生成中：①無料端末内（AIなし）②Cloudflare AI（個人無料枠に接続済みのみ）。生成中は実コマ数`3/5`、進行中のカード、失敗時は再試行。架空の秒数/進捗百分率を表示しない。
- `W06` レビュー：元動画のフレームと生成したコマ、ページ単位のプレビュー、コマ単位再生成、画像の画質調整、保存。
- `W07` 保存・共有完了：保存済みの作品名・ページ枚数・プレビュー。PNG画像ごとの共有。PDF対応は実際にPDF生成処理を作ってから追加。
- `W08` 作品一覧：制作日時・タイトル・ページ・サムネイル、作品の再表示・共有（実際にサポートする操作のみ）。
- `W09` マイデッキ：デッキ選択/新規作成/削除、カード検索、最大12枚/デッキの並び替え・追加/削除、現在のデッキに即反映。
- `W10` 設定/ヘルプ：画質モード、Cloudflare個人接続、無料枠の注意、アクセス権、アプリの説明、3ステップの使い方。

## 2. 一貫するビジュアルルール
- ブランド：ヘッダーにレックス＋黄色文字の「ムビコマ」。旧称「COMIC POP!」は画面上に表示しない。
- 色：明るいブルー `#076FE8`、深いブルー `#09266C`、青白い光 `#10C9FC`、黄色 `#FFE400`、白いカード面 `#ECF7FF`、文字 `#071642`。青地に細かい漫画網点と映画フィルムの演出。黄色は**主要CTA・選択状態・注目点**に絞る。
- レックス：**ゴーグル、白/青/オレンジの顔・身体、映画モチーフの同一キャラ**。ジャンル・ピンカードは実イラスト素材を独立画像で置き、ラベル/枠/ボタンを画像内に焼き込まない。
- iPhone基準幅 `375–430 pt`、左右余白 `10–14 pt`、要素間 `6–12 pt`、角丸 `12–20 pt`。操作領域最小 `44×44 pt`。ヘッダー/下部ナビは SafeArea 対応。
- 太字の丸ゴシック系、漫画風縁取りと影。文字そのものは可能な限り SwiftUI Text とし、日本語の可読性とDynamic Typeへの追従を優先。
- スクロール対象と固定領域を分ける。CTAが下へ押し出される画面では `safeAreaInset` で下部に固定する。機能と無関係な装飾がタップ領域を覆ってはならない。
- 再現画像を**画面全面のPNGとして表示する実装は禁止**。背景装飾・レックス絵・ジャンルカード絵のみ画像素材。動画、ピン、ラベル、トグル、画質調整、ページ移動はネイティブで描画。

## 3. W03 カード挿入スタジオ（最重要）
画面の上下順：
1. 共通ヘッダー：メニュー、レックス＋ムビコマ、ヘルプ、書き出し（未完成時は導線を案内）。
2. 実動画ビュー：アスペクト比維持。未選択時はレックス＋動画選択CTA。選択時は必ず**選択した動画**を表示する。右上の拡大全画面、左下に現在位置/合計時間。
3. 再生操作：戻す5秒、戻す1秒、再生/一時停止、進める1秒、進める5秒。現在時刻とトラックを同期。
4. タイムライン：実動画から抽出した5枚のサムネイル、現在位置の黄色線、挿入済みピンの黄色マーカー、スクラブで即時移動。フレーム取得失敗時も画像の時刻順を崩さない。
5. カード見出しと絞込：「マイデッキ」「お気に入り」「おすすめ」。初期表示はおすすめ、8種類のカード（導入、スロー、ドラマティック、ツッコミ、ひらめき、しんみり、大ゴマ、オチ）。
6. 独立したイラストカード：4列×2段のコンパクト格子、ラベルはネイティブテキスト。**1回タップすると現在再生位置へそのカードを即時挿入**、黄色縁・小さな成功トースト「0:42に『導入』を挿入」。ダブルタップでも2枚になる誤操作を減らすため、保存処理中は同一ボタンを無効化。長押しでお気に入り切替。
7. 「＋挿入」：直前に使用したカードを現在位置に追加。どのカードかをボタン近くに表示。カード未選択・動画未選択・12枚上限は無効化し、理由を説明。
8. 挿入済み一覧：位置、カード名、サムネイル、再生位置へ戻る、個別削除、全削除の確認。異なるタイムスタンプの順序だけでなく**同じ時刻の複数カードも保持**。
9. 下部固定ステップバー：現在②編集を光らせる。③へ進むCTAは最低1枚の有効カードがある場合のみ活性。

**動画変更時**：旧動画に紐づくカード・フレーム・未保存の生成結果を混入させない。動画の再選択時に確認UIと復帰不可の説明を表示。画風やデッキ変更だけで挿入済みカードを削除しない。

## 4. W04 画風選択
- 2列×3行。イラストとラベル：アメコミ系（american）、熱血少年漫画（shonen）、少女漫画（shojo）、ギャグ漫画（gag）、劇画・シネマ（seinen）、ホラー（horror）。
- 選択は単一選択。黄色枠とチェックで見える化。1カードだけが選ばれる。
- 「統一感アップ」4つのスイッチ：「同一キャラ維持」「色調を統一」「場面切替を優先」「元動画に忠実」。これらはCloudflare AI生成時の**プロンプト指示**であり、保証機能ではないことを補足。端末内フィルターでは効かない設定を明示する。
- 白黒／カラーをユーザーが選べる。ジャンル変更時に勝手にユーザー指定カラーを上書きしない（初回選択のみジャンル既定色を設定）。
- ページ数は**挿入カード枚数ではなく生成シーン数**から計算。例：5カード（うち同時刻2枚）→4シーン→1ページ、5つの別々の場面→5シーン→2ページ。タイトルは任意。
- CTA「この画風で漫画を作る」を常時視認しやすく配置。コマ0枚、生成中は無効化。タップ後に生成方法を選ぶ。

## 5. W05 生成中・失敗
- ユーザー自身の動画画像を外部に送る場合は明示して許可・接続させる。端末内は画像送信なし。
- 表示は `n / total コマ`、現在処理中のカードとプレビュー。実コマを確認できない処理で架空のパーセンテージを出さない。
- Cloudflareで利用枠不足・回線エラー・画像審査・タイムアウトを区別し、それぞれ分かる日本語説明を表示。
- 途中失敗は成功済みを保持し、同一動画/ピン順/画風/色/方式なら残りから再開。未完成結果は保存不可。生成中の中止機能は実際に安全なキャンセル処理を実装した場合だけ表示。
- 戻った場合も選択したカードと設定を保持。生成方式・画風・元動画が変わった場合は以前の出力と混ぜない。

## 6. W06 レビュー／品質調整
- 上部：動画から取り出した**元フレーム**と該当**生成コマ**を隣に表示。タップして編集中コマを選択。
- 中部：ページ画像の大きいプレビュー。左右ボタンでページ送り、全画面拡大。小型iPhoneではプレビュー優先。コントロールは下段／折りたたみへ移す。
- 「このコマだけ再生成」は該当ピンのIDを維持し、その他のコマを消さない。オンライン再生成は無料枠を追加消費することを表示。
- 操作可能な画質調整は `コントラスト` `明るさ` `彩度` `輪郭強調`。反映ボタンで本当にCore Imageの処理を実行する。調整前の画像を保持し、スライダーを繰り返しても劣化を累積させない。
- 実測していない「人物一致98%」「場面検出97%」などの**架空の品質パーセンテージは表示しない**。将来の自動評価を表示する場合は測定根拠・対象コマ・モデル・意味を併記。
- 全カードが存在し、コマID順序一致かつページ枚数一致のときだけ保存可能。保存後は成功画面へ。

## 7. W07〜W10 補助画面の実用要件
- 作品保存・共有：保存成功メッセージ、作品名、ページ数、PNG一覧、画像単位のShareLink/写真保存。未実装のPDF/印刷を有効なボタンにしない。
- 作品一覧：空状態には「動画から作る」を表示。作品は作成日時、ページ枚数、タイトル、サムネイルが識別できる。
- マイデッキ：最大20デッキ、1デッキ12カード。新規デッキの作成、選択、追加/削除、並び替え。お気に入りはデッキ所属と別データとして管理。
- 設定：画風/色の既定値、無料おためし説明、Cloudflare Free契約の注意（アプリが課金を防げない）、権限、ヘルプ。
- 初回案内：説明は最大3ステップ。いつでもヘルプから再表示できる。

## 8. UI状態の一覧（画面の実装時に各状態を描く）
| 状態 | 表示 | 主操作 |
|---|---|---|
| 空・初回 | レックスと動画選択CTA | 動画を選ぶ |
| 動画読込中 | 読込表示、重複操作無効 | 何を待っているか表示 |
| 動画読込失敗 | 原因＋再選択 | 再試行 |
| 動画あり・ピン0枚 | ビデオとおすすめカード | カード挿入 |
| ピン1〜12枚 | ピンの時刻・数・削除 | 画風選択へ |
| 画風未選択 | 6ジャンル＋既定選択 | 画風指定 |
| AI未接続 | 端末内モードは有効 | おためし生成／設定 |
| 生成中 | 完了コマ数と対象カード | 重複開始防止 |
| 途中失敗 | 成功済みのコマとエラー | 残りから再試行 |
| 完全生成済み | 比較と編集・保存 | 作品に保存 |
| 保存失敗 | 元データ保持＋原因 | 保存再試行 |
| 保存済み | 作品名、ページ、共有 | 画像を共有／一覧に戻る |

- `PopEditor.swift` → W02/W03 動画・カード・タイムライン

## 10. 受け入れテスト（合格基準）
1. iPhone幅375/390/430ptで、主要CTAと下部工程ナビが隠れず、文字が切れない。
2. 動画を切り替えると旧ピンと旧生成結果が混じらない。画風変更だけならピンは保持。
3. ±1秒/±5秒・スクラブが実動画の時刻に連動し、カード挿入時刻とスナップショットが一致。
4. 同じ時刻（おおむね1.5秒以内）のカードは一つのシーンに統合し、全部の役割を1コマに合成。4つの別々のシーン→4コマ1ページ、5つの別々のシーン→5コマ2ページ、12シーン→12コマ3ページ。カードの挿入情報は全件保持。
5. レックスのキャラが全画面で統一され、絵文字・文字のみのジャンルボタンに戻らない。
6. AI接続なしで端末内簡易生成を試せる。AI生成とは画面上で区別し、アップロード前に説明する。
7. 途中失敗からの再試行で完成済みコマを保持。未完成状態の保存は禁止。
8. コマ単位再生成・画質スライダーが実際の画像に反映され、他のコマは不用意に変わらない。
9. 作品保存とPNG共有は端末実機で確認。架空の精度数値、未実装PDF、偽の進捗を表示しない。
10. VoiceOver、Dynamic Type、色弱を含む視認性、誤タップ防止、iPhone12の発熱/スムーズさを検証。

**重要**：本書と画像は今後のUI改修における正本。SwiftUI実機キャプチャとの1対1画像比較・Codemagicでのビルドが完了するまでは、デザイン完全一致と宣言しない。
